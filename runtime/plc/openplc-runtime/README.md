# OpenPLC Runtime

This directory integrates the [OpenPLC Runtime v3](https://github.com/thiagoralves/OpenPLC_v3) — an open-source IEC 61131-3 PLC runtime engine.

## Installation

Run the install script to clone and set up the OpenPLC Runtime:

```bash
bash install.sh
```

This will:
1. Clone the OpenPLC Runtime from https://github.com/thiagoralves/OpenPLC_v3
2. Run the OpenPLC installer for your platform
3. Start the OpenPLC Runtime service
