# OpenPLC Editor

This directory integrates the [OpenPLC Editor](https://github.com/thiagoralves/OpenPLC_Editor) — an open-source IEC 61131-3 PLC programming environment.

## Installation

Run the install script to clone and set up the OpenPLC Editor:

```bash
bash install.sh
```

This will:
1. Clone the OpenPLC Editor from https://github.com/thiagoralves/OpenPLC_Editor
2. Install required dependencies
3. Launch the editor
