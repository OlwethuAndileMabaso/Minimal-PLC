# Mobile

Native mobile apps for **Android** and **iOS** that connect to the Minimal-PLC runtime web interface.

Both apps open the runtime's web interface (`http://<target>:8080`) in a full-screen WebView, giving operators a native-feeling app on their phone or tablet.
